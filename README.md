# fitness_store_sales_report
This interactive Power BI dashboard provides a comprehensive business intelligence overview of sales performance in the fitness industry. Designed to help stakeholders analyze trends, customer behavior, and product performance, the dashboard integrates multiple visualizations and filters for dynamic exploration.
## 📊 Key Features
• 	Top-Level Metrics
• 	Total Sales: ₹103,590
• 	Total Orders: 30
• 	Average Unit Price: ₹3,277.33
### Sales Breakdown
• 	By Category: Fitness Gear (₹79K), Supplements (₹13K), Apparel (₹7K), Accessories (₹4K)
• 	By Region: South (57.82%), East (27.22%), North (7.91%), West (minor segment)
• 	By Product: Treadmill, Rowing Machine, Exercise Bike, Whey Protein
### Time-Based Analysis
• 	Sales by Order Date: Highlights peak sales days (e.g., ₹24K on Jan 12)
• 	Order Quantity by Time of Day: Area chart showing order volumes between 11:00 and 19:00
### Customer Insights
• 	Average Sale by Gender: Male (₹4.2K), Female (₹2.1K)
• 	Delivery Status: Delivered (86.67%), Pending (10%), Returned (3.33%)
• 	Interactive Filters
• 	Order Date, Category, Region, Customer Gender, Payment Mode, Delivery Status
## 🎯 Purpose
This dashboard was built to:
• 	Monitor sales performance across products and regions
• 	Understand customer demographics and buying patterns
• 	Track delivery efficiency and order fulfillment
• 	Enable data-driven decisions for marketing and inventory planning
## 🛠️ Tools Used
• 	Power BI Desktop
